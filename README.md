# 海水淡化 · 反渗透 RO（3D 交互课件）

工业科普用的海水反渗透淡化厂三维课件。画面是深海军蓝的厂区全景，知识点都绑在可点击的设备上：点设备，相机会飞近，右侧知识面板同步换内容。

本地打开（需要一个静态服务器，不要直接双击 html，浏览器会拦截模块脚本）：

```bash
python3 -m http.server 8734
```

然后访问 `http://127.0.0.1:8734/`。

也可以用任意静态托管。把整个目录放到 GitHub Pages 即可，无需构建。

## 可以做什么

- 开场从远处落到厂区全景。全景是锐的，景深光圈为 0。
- 底部时间轴：取水 → 预处理（混凝 / 过滤 / 加药）→ 反渗透（高压泵 / RO 膜组 / 能量回收）→ 成品（后处理 / 淡水罐）。
- 点击三维设备或悬浮标签，镜头飞近，知识面板更新。全景、以及拖动旋转时，景深关闭；停在近景上时，光圈约 0.7、最大模糊约 5.6（与画面设置里的数值一致）。对焦落在当前设备上，不跟鼠标。
- 玻璃管内有等间距、一起移动的细箭头，方向即流向；旁边是半透明的水粒子，不是实心小球。
- 「开始运行 / 停止运行」控制管内流动、搅拌、高压泵压力表示意和膜组剖视里的水、盐粒子。压力示意落在约 5–8 MPa，不是某一座真实工厂的记录。
- 「自动讲解」按流程飞到各设备，并用浏览器的中文语音朗读（若系统没有中文语音，仍然会切镜头和面板）。
- 「音效」「全部叠合」「重置」「全屏」，以及齿轮里的泛光、灯光、画质和景深。
- 方向键切换设备，Esc 回全景，空格开关运行。
- 地址栏可加 `?unit=membrane`（或 intake、coag、filter、dose、pump、erd、post、tank）直接落到该设备，`?intro=0` 跳过开场。

## 文件

- `index.html`：页面、界面和开发者工具遮罩
- `js/content.js`：各设备的中文说明
- `js/plant.js`：厂区模型、管道、箭头和粒子
- `js/main.js`：渲染、后期、镜头和交互
- `vendor/three/`：Three.js、后期通道，以及海水用的 Water2（Reflector / Refractor 和水面法线贴图）
- `fonts/course.woff2`：课件用到的中文字形

画面设置里的「低 / 中 / 高」会改分辨率和粒子数量。低画质仍然走 Bokeh 景深，近景不会变成一片糊。

科学口径按教材来：海水渗透压大约 2.5–3 MPa，海水反渗透操作压力约 5–8 MPa，净透水需要 P > π（更准确是 ΔP − Δπ）。膜组剖视区分水的透过和盐的截留。没有编造产量、能耗百分比或某一厂的运行日志。
