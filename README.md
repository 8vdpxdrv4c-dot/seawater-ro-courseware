# 海水淡化 · 反渗透 RO（3D 交互课件）

工业科普用的海水反渗透淡化厂三维课件。开场是白天海岸：浅灰混凝土栈桥、暖色沙丘、近岸青绿到外海深蓝。知识点都绑在可点击的设备上：点设备，相机会飞近，右侧知识面板同步换内容。

本地打开（需要一个静态服务器，不要直接双击 html，浏览器会拦截模块脚本）：

```bash
python3 -m http.server 8734
```

然后访问 `http://127.0.0.1:8734/`。

也可以用任意静态托管。把整个目录放到 GitHub Pages 即可，无需构建。

## 可以做什么

- 开场从远处落到厂区全景。全景是锐的，景深光圈为 0。
- 底部时间轴：取水 → 预处理（混凝 / 过滤 / 加药）→ 反渗透（高压泵 / RO 膜组 / 能量回收）→ 成品（后处理 / 淡水罐）。
- 点击三维设备或悬浮标签，镜头飞近，知识面板更新。全景、以及拖动旋转时，景深关闭；停在近景上时，光圈约 0.7、最大模糊约 5.6（与画面设置里的数值一致）。对焦落在当前设备上，不跟鼠标。
- 玻璃管内有等间距、一起移动的细箭头，方向即流向；旁边是半透明的水粒子，不是实心小球。
- 「开始运行 / 停止运行」控制管内流动、搅拌、高压泵压力表示意和膜组剖视里的水、盐粒子。压力示意落在约 5–8 MPa，不是某一座真实工厂的记录。
- 「自动讲解」按流程飞到各设备，并用浏览器的中文语音朗读（若系统没有中文语音，仍然会切镜头和面板）。
- 「音效」「全部叠合」「重置」「全屏」，以及齿轮里的泛光、灯光、画质和景深。
- 方向键切换设备，Esc 回全景，空格开关运行。
- 地址栏可加 `?unit=membrane`（或 intake、coag、filter、dose、pump、erd、post、tank）直接落到该设备，`?intro=0` 跳过开场。

## 文件

- `index.html`：页面、界面和开发者工具遮罩
- `js/content.js`：各设备的中文说明
- `js/plant.js`：厂区模型、管道、箭头和粒子
- `js/main.js`：渲染、后期、镜头和交互
- `js/ocean.js`：包围厂区岛屿的 Ultra-Water FFT 海面，铺到天际线
- `vendor/three/`：Three.js 和后期通道
- `vendor/ultra-water/`：Ultra-Water 的海面模拟（MIT，见该目录 LICENSE）
- `fonts/course.woff2`：课件用到的中文字形

画面设置里的「低 / 中 / 高」会改分辨率和粒子数量。低画质仍然走 Bokeh 景深，近景不会变成一片糊。

科学口径按教材来：海水渗透压大约 2.5–3 MPa，海水反渗透操作压力约 5–8 MPa，净透水需要 P > π（更准确是 ΔP − Δπ）。膜组剖视区分水的透过和盐的截留。没有编造产量、能耗百分比或某一厂的运行日志。

## 海水

外海是 [Ultra-Water](https://github.com/8vdpxdrv4c-dot/Ultra-Water) 的 FFT 海面，铺到天际线，从四面把厂区岛屿围住。天空和云也是这套库的大气（白天，太阳高度约 48°）。沙地和沙丘偏深。设备、阴影和金属仍在。工艺水池里的水面仍是普通材质。源码在 `vendor/ultra-water/`。低画质会减网格、关掉平面反射和焦散。

## 海水三轮

下面是改用 FFT 海面之前的 Water2 记录。

1. 原先偏亮、反射约 0.5、波浪块太大、流动偏快，折射底下是一块纯色，看起来像塑料板。改成更深的水色、基础反射约 0.2、更慢的沿岸流、更密的浪纹，折射层做成近岸浅、离岸深，并在堤边加了一条薄泡沫。
2. 近看仍像一块暗板，堤岸是一条直线。把基础反射收到约 0.3，海底加上近岸碎斑，堤脚加了湿痕，岸边和取水口附近放了湿石头和断开的泡沫，避免一整条白边。
3. 全景里远海被雾吃成灰片，浪纹从厂区镜头看不出来。关掉水面材质上的雾，把 Water2 法线扰动从泳池用的 0.05 提到 0.16，浪纹尺度调到 22，颜色 `#1a4554`，反射 0.32，流速 0.018，并在靠近镜头的堤角加了更大的石头和泡沫。全景光圈仍是 0，点取水口仍会飞近。
4. `#1a4554` 会乘进反射和折射，再叠上近黑的海底和暗天空，海面被压成一片黑。水色改为 `#a9cdd8`，反射 0.34，流速 0.022，法线扰动收回 0.09。海底近岸 `(0.11, 0.30, 0.34)`、外海 `(0.045, 0.16, 0.24)`，双面可见。岸边保留湿痕和断续泡沫。
5. 泛光过强，岸边石头去掉。泛光强度 0.14、阈值 0.94、半径 0.22。路灯自发光约 1.15，点光约 1.05。主光和曝光不动。
6. 按白天海岸设计稿重做地面、沙地和海水，开场镜头改到能看见海湾。地面贴图 `#dfe3e8`，混凝土 `#e7e9ec`，堤墙 `#c9ccc8`。沙地贴图 `#f0c98a`、材质 `#f6d7a4`，远丘 `#e8c98a`。Water2 颜色 `#69b7e2`，反射 0.20，尺度 12，流速 0.016。海底近岸 `(0.22, 0.95, 0.92)`、外海 `(0.015, 0.20, 0.55)`。没有岸石。
7. 晴天。天空是蓝色穹顶加程序化白云和太阳盘，天顶 `(0.05, 0.32, 0.92)`。雾 `#c5ddf6`，近 380 远 820。主光 `#fff2d6` 强度 2.25，位置 `(58, 34, 16)`，阴影正交约 ±80 / ±62，近 2 远 220。半球光 `#7eb6ef` / `#e4c48e` 强度 0.52。环境反射 0.72，曝光 0.84。钢材金属度 0.94 粗糙度 0.20，不锈钢 0.97 / 0.11，水箱 0.90 / 0.14，黄色管件 0.64 / 0.26。泛光仍是 0.14 / 0.94 / 0.22。开场镜头 `(92, 22, 102)` 看向 `(10, 2.4, -2)`，视场 46°，天际线以上能看到蓝天。
8. 地面和海水是同一个大圆盘。圆心 `(22, 0, 2)`，半径 104。岸线 `x = -14.2` 把圆切成陆侧沙地和海侧 Water2；水面几何仍在 XY 平面，绕 X 转 -90° 后铺平。外缘是管径 0.38 的圆环，外面再淡出 18 米。混凝土栈桥放在圆盘上。
